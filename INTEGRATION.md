# Подключение на сайте дилера

## Встраивание

Рекомендуемая схема: игра и API на отдельном HTTPS-поддомене, блок iframe на странице ST9. Хост игры должен быть доступен посетителям без входа в ChatGPT; приватная ссылка Sites годится для просмотра владельцем.

```html
<section aria-label="Игра SOLLERS Traffic Rush">
  <iframe
    src="https://game.sollers-avilon.ru/"
    title="SOLLERS Traffic Rush"
    style="display:block;width:100%;max-width:460px;height:min(820px,90dvh);min-height:540px;border:0;border-radius:16px;margin:auto"
    allow="autoplay; fullscreen"
    allowfullscreen
  ></iframe>
</section>
```

Адрес `game.sollers-avilon.ru` выше — пример поддомена, который должен настроить администратор; он не был создан в рамках прототипа. Добавьте фактический хост в frame-src CSP страницы дилера. На хосте игры разрешите frame-ancestors домена дилера. Из-за Canvas и формы не используйте iframe sandbox без нужных разрешений скриптам, формам, popups и same-origin.

## Переменные сервера

В Sites задайте через настройки окружения. Для локальной проверки используйте игнорируемый файл `.dev.vars`, не помещайте секреты в клиент, Git или чат.

| Переменная | Назначение |
|---|---|
| SOCIAL_URL | HTTPS-ссылка на страницу/канал дилера |
| SOCIAL_LABEL | Короткое имя сети, например VK или TELEGRAM |
| CONTINUE_MODE | alternate (соцсети/телефон по очереди), phone-third (телефон каждое третье продолжение), choice (выбор) |
| CRM_WEBHOOK_URL | HTTPS endpoint приёма заявки в CRM или промежуточном интеграторе |
| CRM_WEBHOOK_TOKEN | Необязательный Bearer-токен webhook |
| PRIVACY_URL | Ссылка на согласованные условия обработки данных и звонка дилера |
| CONSENT_VERSION | Версия текста согласия, по умолчанию st9-lead-v1 |
| ADMIN_TOKEN | Секрет для просмотра очереди заявок и повтора доставки |

Форма телефона включается только если заданы CRM_WEBHOOK_URL и PRIVACY_URL. Пользователь отмечает согласие отдельно. Телефон нормализуется в формат +7XXXXXXXXXX; принимаются номера, начинающиеся с 7 или 8. SMS пока нет, владение номером не подтверждается.

## CRM

Сервер посылает POST JSON:
```json
{
  "external_id": "opaque-run-id:2",
  "source": "SOLLERS Traffic Rush",
  "model": "ST9",
  "phone": "+7XXXXXXXXXX",
  "score": 123,
  "consent": {"accepted": true, "at": "ISO-8601 timestamp", "version": "st9-lead-v1"},
  "created_at": "ISO-8601 timestamp"
}
```

Заголовок Idempotency-Key совпадает с external_id. Приёмник обязан дедуплицировать по этому ключу. Ответ 2xx означает успешную передачу. Не настраивайте CRM_WEBHOOK_URL напрямую на произвольный метод Битрикс24/amoCRM: сначала нужен адаптер под схему конкретной CRM и её способ авторизации.

Заявка сохраняется до сетевого запроса. Доставка занимает не больше 8 секунд. При ошибке статус остаётся pending; счётчик попыток увеличивается. Текущая версия повторяет отправку по авторизованному запросу оператора, самостоятельный планировщик повторов ещё не подключён.

- GET /api/admin/leads — последние 100 заявок и статус передачи.
- POST /api/admin/retry — повторить до 10 ожидающих заявок, максимум 20 попыток на заявку.
- Оба запроса требуют Authorization: Bearer ADMIN_TOKEN. Не вызывайте их из публичного интерфейса.

Публичные API не возвращают телефон и согласие. В лидерах только позывной, очки и дистанция. Владелец CRM определяет сроки хранения и окончательный текст согласия до публичного запуска.

## Соцсети и результаты

Ссылки не выдуманы. Без SOCIAL_URL доступна помеченная демопопытка. При заданной ссылке — переход в сеть и кнопка самоподтверждения подписки. Для настоящей проверки нужны название сети, аккаунт/канал и её разрешённый серверный механизм проверки. Автоматическая проверка пока не заявляется.

Таблица хранит лучшие заезды, один результат на заезд. Сервер выдаёт случайный токен заезда, проверяет его при записи, ограничивает темп создания заездов и правдоподобие очков/дистанции по времени. Физика остаётся на клиенте: для призового соревнования нужна дополнительная серверная верификация повтора, текущая таблица предназначена для промоаркады.

## Что требуется от дилера

Название CRM и способ интеграции; официальные ссылки соцсетей; правило предложения телефона; текст/URL согласия; публичный домен для игры и доступ администратора страницы для установки iframe.
