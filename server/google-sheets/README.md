# Общая таблица результатов

`Code.gs` публикуется как веб-приложение Google Apps Script от имени владельца с доступом «Все». Сама Google Таблица остаётся закрытой. Скрипт использует только созданную для игры таблицу, её ID хранится в свойствах проекта.

1. Вставить `Code.gs` в проект Apps Script и выполнить `setupLeaderboard` один раз. Повторный запуск использует ту же таблицу.
2. Разрешить скрипту работу с Google Таблицами. Google запрашивает область доступа к таблицам аккаунта; сам код обращается только к ID в `SPREADSHEET_ID`.
3. Развернуть веб-приложение: выполнять от имени владельца, доступ для всех, включая посетителей без Google-аккаунта.
4. Записать URL, заканчивающийся на `/exec`, в `src/config/leaderboard.ts` и опубликовать игру.

GET `?action=leaderboard` отдаёт 50 лучших результатов: место, позывной, очки и дистанцию. Кэш обновляется через 10 секунд или после записи. POST с `Content-Type: text/plain;charset=UTF-8` принимает JSON: `action: runs` выдаёт подписанный токен, `action: scores` сохраняет результат. Простой запрос не требует CORS preflight; ответ Google ContentService приходит после перенаправления.

Подпись и время выдачи проверяются сервером. Токен действует сутки. Правдоподобие очков и дистанции ограничено длительностью заезда. Повторная отправка того же результата не создаёт дублей. Записи защищены блокировкой, а публичный ответ не содержит ID заезда и токенов. Формулы в позывном отвергаются. Это базовая защита промоигры: физика остаётся на клиенте, сервер не воспроизводит весь заезд.

Для Apps Script действуют квоты Google; при большом трафике потребуется отдельный сервер. В таблицу не добавляются демонстрационные игроки. Изменения кода нужно публиковать новой версией существующего развёртывания, сохраняя URL.

`node scripts/test-google-sheets.mjs` проверяет API с изолированной моделью таблицы и не отправляет тестовые результаты в Google.
