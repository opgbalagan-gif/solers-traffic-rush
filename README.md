# SOLLERS Traffic Rush

Браузерная аркада для страницы дилера SOLLERS ST9. Phaser 3 + React, перспективная трасса и растровые игровые спрайты. Blender, Unreal Engine и Godot для запуска этой версии не нужны.

## Что работает

- Главное меню, два водителя, гараж и палитры из предоставленных концептов.
- Перед каждым новым заездом: загрузка трассы, наглядные правила поверх неподвижной игровой сцены и стартовый отсчёт после нажатия «Начать заезд». Анимация пальца показывает свайп, пульсирующее удержание — азот. Пока открыты правила, симуляция и таймер ждут.
- Крупное исходное изображение ST9 с сайта дилера, отдельные надписи названия и единая окраска кузова в гараже и на трассе без зависимости от фильтров браузера.
- ST9 и пять типов трафика; лес, осень и зимний участок сменяются каждые 750 метров.
- Единая перспектива дороги, машин и разметки; плавные повороты, отбойники, разные деревья, коттеджи, склад и щиты SOLLERS.
- Стартовый отсчёт, руление с инерцией и немедленная реакция на свайп. Симуляция не зависит от частоты кадров.
- Трафик держит дистанцию, тормозит за лидером и предупреждает поворотником о перестроении. В каждой группе остаётся свободная полоса.
- Клавиши ←/→ или A/D и свайпы. На трассе остаются небольшие сердечки жизней и компактная кнопка паузы справа вверху. Пауза также доступна через Esc; в ней можно продолжить заезд, посмотреть напоминание управления и завершить заезд.
- Азот работает при удержании экрана или пробела. Отпускание сразу прекращает расход; полного заряда хватает на 4 секунды. Свайпы и короткие касания не расходуют азот.
- Очки появляются короткой анимацией за чистые обгоны, опасные сближения и бонусы. Общий счёт плавно растёт; рядом показана серия обгонов.
- Три жизни. Удар снимает одну жизнь; 2,8 секунды прозрачности защищают от повторного урона.
- После третьего удара — продолжение с тем же счётом и тремя новыми жизнями.
- По умолчанию: первое продолжение через соцсети, второе через телефон, затем чередование.
- Серия обгонов, ящики +10, задания, звук двигателя, пауза при скрытии вкладки.
- Близкий обгон без касания даёт +15 и заряд ускорения. Столкнувшиеся машины не дают бонус за чистый обгон.
- Искры, дым шин, свечение ускорения, звуки бонусов и двигателя; настройки уменьшенного движения учитываются.
- Общая таблица лучших заездов. Для GitHub Pages предусмотрен Google Apps Script с закрытой Google Таблицей; локально остаётся D1. Игрок публикует результат под выбранным позывным.
- Заявки с согласием сохраняются в D1, затем передаются сервером в CRM через webhook. При сбое остаются в очереди.
- Сервис-воркер кэширует только ресурсы игры, API и личные данные не кэшируются.

## Локальный запуск

Node.js 22+ и pnpm. Все зависимости уже описаны в package.json.

```powershell
pnpm install
pnpm build
pnpm start
```

Откройте http://127.0.0.1:4173. Команда start применяет локальные миграции и запускает игру вместе с API и локальной D1.
Для изменения интерфейса с HMR остаётся `pnpm dev` (Vinext); полный сервер проверяйте через build/start.
`pnpm test` проверяет механику и сервер с отдельной базой в памяти и подставным CRM endpoint. Настоящие заявки при тестировании не отправляются.
Проверка заезда включает 10 000 вариантов размещения групп трафика, 12 трёхминутных симуляций, совпадение расчётов при 30/60/120 fps и отсутствие невидимых столкновений. Это тесты игровой логики, а не замер FPS на реальных устройствах.

## Готовность интеграций

В этой поставке нет настроенных CRM, социальных ссылок и документа согласия дилера. Поэтому настоящие телефоны не собираются; экраны продолжения явно предлагают деморежим. Общая таблица лидеров работает через настроенный Google Apps Script либо при запуске сервера с D1.

Переход в соцсеть не подтверждает подписку. При настроенной ссылке сейчас используется явное подтверждение игрока; автоматическую проверку нужно подключать отдельно через поддерживаемый API/бот выбранной сети. SMS-верификация не реализована и не имитируется.

## Размещение

`pnpm build` создаёт `out/` с интерфейсом и `dist/` с Worker и ресурсами для Sites. База управляется миграциями Drizzle в `drizzle/`.
`pnpm build:pages` создаёт статическую игру для GitHub Pages. Адрес опубликованного Google Apps Script задаётся в `src/config/leaderboard.ts`; без него общая таблица требует отдельного Worker API. Сервер Google Таблиц находится в `server/google-sheets/Code.gs`, не хранит телефоны и не включает CRM-форму.

Портреты водителей взяты из пользовательских референсов, фото ST9 для меню и гаража — с сайта дилера; игровой ST9 — самостоятельный растровый рендер. Это 2.5D-прототип. Для точного соответствия серийной машине во всех ракурсах нужна утверждённая 3D-модель ST9 и отдельная подготовка материалов/анимаций. Картинка движущегося окружения не является попиксельной копией концепта.
